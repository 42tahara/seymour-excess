```
# H = C5(1,2)(5頂点正則トーナメント、強連結 oriented)、サイズ (4,4,4,4,4)、cap 0:
```

δ⁺ ≥ 8 のメンバーが n=20 に存在する — 「最小出次数の条件により n < 24 で空」は偽。
j=0 の頂点の出次数は R 弧のみ(min(0,c)=0)なので δ⁺(G) = min_a Σ_{b∈N⁺_H(a)} n_b。
m=3(H=C₃)ではこれが「全 n_a ≥ 8 → n ≥ 24」を強制するが、m=5 の商は出次数2を
2クラスに分配でき 4+4=8 で足りる。**m=3 でのみ正しい論法の族全体への外挿**である。
(内部逆解きの「可行例の min n は 24」は excess≤3 可行インスタンスの min n であり、
族メンバーシップの min n ではない — この読み替えが誤りの発生源と推定される。)

## 4. 反駁の試みと結果

1. **T9 空虚性への反駁(成功 → 差し戻し)**: 「δ⁺≥8 → n≥24」が族全体で成り立つ
   というなら m≥4 の商で反例が組めるはず。→ C₅(1,2)・(4,4,4,4,4) で n=20 の
   メンバーを構成、公開検証器で δ⁺=8 を確認。**反駁成功**(§3.4)。
2. **T9 主命題への反駁(失敗)**: 新たに開いた n=20..23 帯で excess ≤ 2 または
   3∤n の excess=3 が出れば主命題ごと崩れる。→ 633,125 件で違反 0。**反駁失敗**
   (主命題は生きている。ただしこれは単一商のプローブであり、全 4,313 商の
   n=20..23 帯の再確認は §5-1 の宿題)。
3. **T8 への反駁(失敗)**: 巡回クラス(頂点推移的)の外に margin ≠ 0 の正則
   トーナメントがあれば偽。→ walk 25,000 サンプル(非推移証明書 25,000/25,000)で
   違反 0。証明書判定自体の陰性対照も確認。**反駁失敗**。
4. **T6 散文の再乖離探し(失敗)**: 起草側が1件自己検出した後にもう1件ないか、
   公開 jsonl の全行を README の主張と突き合わせ。→ 「n ≤ 28 および n = 30」
   「29 は UNKNOWN」は公開ログと完全一致。**反駁失敗**。
5. **定義分離への反駁(失敗)**: 「不能性は大クラス→部分クラス」が min の向きで
   逆転していないか。→ E_δ(n) ≤ E_δ^sc(n)(部分クラスの min は大きい)、下界 L は
   大クラスで証明 → 両方 ≥ L。**論理に穴なし**。
6. **除外タプル裁定への反駁(半分成功)**: manifest 登録の方が堅いのでは。
   → manifest は adjacency sha1 の台帳であり登録は圏の誤り(提案書に同意)。
   ただし提案書が「より堅い代替」と呼ぶ parse ベース規則は実際には**より弱い**
   (破損 witness の無言スキップ)。この点のみ提案書の評価を訂正する。
