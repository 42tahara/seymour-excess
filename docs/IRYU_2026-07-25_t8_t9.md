## 課題 1

1. 証明に本質的な誤りはありません。  
   問題の一歩：

   「`w ∉ B(v)` なら、任意の `y ∈ A(v)` について `w -> y`」

   は、すでに `D` がトーナメントであることを示した後なら正しいです。  
   なぜなら `y ∈ A(v)` なので `v -> y`。もし `y -> w` なら `v -> y -> w` が長さ2の有向路になり、`w ∈ B(v)` となって仮定に反します。トーナメントなので `w,y` 間には必ず一方向の弧があり、よって `w -> y` です。

2. 反例はありません。  
   出次数下限 `k` から、弧数は
   \[
   \sum_v d^+(v) \ge (2k+1)k=\binom{2k+1}{2}
   \]
   ですが、単純有向グラフなので弧数は高々 \(\binom{2k+1}{2}\)。よって全対がちょうど一方向に結ばれ、全出次数が `k` の正則トーナメントです。各頂点は最大出次数頂点なので 2-king であり、非出近傍の全頂点が距離2に入るため `|B(v)|=k=|A(v)|`。したがって各頂点の寄与は `max(0,0+1)=1`、`S(D)=n`。

3. これは新規ではなく、古典的事実の言い換えです。  
   標準的には「トーナメントの最大出次数頂点は king / 2-king」という事実です。正則トーナメントでは全頂点が最大出次数なので、全頂点が 2-king になります。さらに頂点数が `2k+1` なら出次数も非出近傍数も `k` なので `|B(v)|=|A(v)|` が従います。

   位置づけは **folklore / 既知結果の即時系** が妥当です。「正則トーナメントの全頂点で `|B(v)|=|A(v)|`」という名前付き定理としてよりも、king theorem や Seymour second neighborhood property の自明な特殊例として扱うのが自然です。

   参照例: West の open problems page は Seymour second neighborhood conjecture と tournament case を整理しています。最大出次数頂点が king である事実は tournament kings の標準補題として広く使われています。  
   https://dwest.web.illinois.edu/openp/2ndnbhd.html  
   https://www.sciencedirect.com/science/article/pii/S0166218X15005181

4. 出次数下限を `k-1` に緩めると、まず `S(D)=n` は壊れます。  
   例として `k=2, n=5` で、出近傍を
   \[
   A(0)=\{3,4\},\ A(1)=\{3,4\},\ A(2)=\{3\},\ A(3)=\{4\},\ A(4)=\{2\}
   \]
   とすると最小出次数は `1=k-1` で、実計算により `S(D)=3 < 5` です。
