## 0. 定義(すべての対象と量化子)

- **oriented graph**: 有限有向グラフで、ループを持たず、2-cycle(digon)を持たない。
  すなわち任意の非順序対 {i,j} が担う弧は最大1本。
- `N⁺(v)` = v の出近傍。`N⁺⁺(v)` = `{x : dist⁺(v,x) = 2}`(**ちょうど**距離2)。
  定義より `N⁺(v)`、`N⁺⁺(v)`、`{v}` は互いに素。
- `d₁(v) = |N⁺(v)|`、`d₂(v) = |N⁺⁺(v)|`、**margin** `m(v) = d₂(v) − d₁(v)`。
- `excess(G) = Σ_{v∈V(G)} max(0, m(v) + 1)`。
- **許容グラフ(n = 17)** := 17頂点の oriented graph で `δ⁺ ≥ 8` を満たすもの。
  この集合を `A₁₇` と書く(強連結性は課さない)。
  **強連結許容グラフ**の集合を `A₁₇^sc ⊆ A₁₇` と書く。
- `E_{δ≥8}(17) := min{ excess(G) : G ∈ A₁₇^sc }`。
  (公開 note §1 の定義に従い強連結を課す。`A₁₇^sc` が空でないことは §1 Step 3 で示す。)

`A₁₇` は有限集合であり、以下の主張はその全要素についての全称命題である。

## 1. 審査対象の主張と証明

> **主張 N2(強い形)**: `∀ G ∈ A₁₇ : excess(G) = 17`。
> **主張 N1**: `E_{δ≥8}(17) = 17`。

### Step 1 — `A₁₇` の元は次数 8 の正則トーナメントに強制される

`G ∈ A₁₇` とする。oriented graph は各非順序対につき最大1本の弧しか持たないので
弧数 `|A(G)| ≤ C(17,2) = 136`。一方 `δ⁺(G) ≥ 8` より
`|A(G)| = Σ_v d⁺(v) ≥ 17 · 8 = 136`。よって

- `|A(G)| = 136`、したがって**すべての非順序対が正確に1本の弧を担う**(= トーナメント)、かつ
- `Σ_v d⁺(v) = 136 = 17 · 8` と `d⁺(v) ≥ 8` より **`d⁺(v) = 8` が全 v で成立**(= 正則)。

ゆえに `A₁₇` = 「17頂点の次数 8 の正則トーナメント全体」。

### Step 2 — 正則トーナメントの全頂点は tight(`m(v) = 0`)

`G` を Step 1 の正則トーナメント、`v ∈ V` を任意に固定する。トーナメントなので
`V = {v} ⊔ N⁺(v) ⊔ N⁻(v)`、`|N⁺(v)| = |N⁻(v)| = 8`。

(⊆) `N⁺⁺(v)` は定義により `N⁺(v) ∪ {v}` と交わらないので `N⁺⁺(v) ⊆ N⁻(v)`。

(⊇) `u ∈ N⁻(v)`(すなわち `u → v`)を取る。**`w → u` を満たす `w ∈ N⁺(v)` が存在しない**と
仮定する。トーナメントなので `N⁺(v)` の各 `w` は `u` と隣接し、`w → u` が無いなら `u → w`。
よって `N⁺(v) ⊆ N⁺(u)`。さらに `u → v` より `v ∈ N⁺(u)` であり、`v ∉ N⁺(v)`。
ゆえに `|N⁺(u)| ≥ |N⁺(v)| + 1 = 9`、これは正則性(`d⁺(u) = 8`)に矛盾。
よって `w ∈ N⁺(v)`、`w → u` が存在し `v → w → u` は長さ2の路。
`u ∉ N⁺(v)`(`u ∈ N⁻(v)` かつトーナメントなので両立しない)かつ `u ≠ v` なので
`dist⁺(v,u)` は**ちょうど 2**。したがって `u ∈ N⁺⁺(v)`。

よって `N⁺⁺(v) = N⁻(v)`、`d₂(v) = 8 = d₁(v)`、`m(v) = 0`。v は任意だったので全頂点で成立。

### Step 3 — 結論

Step 2 より `excess(G) = Σ_v max(0, 0 + 1) = 17`(`∀ G ∈ A₁₇`)。これが **N2**。

`A₁₇^sc ⊆ A₁₇` なので `A₁₇^sc` の元も excess 17。`A₁₇^sc ≠ ∅` は具体元で示される:
巡回グラフ `C₁₇(1,…,8)`(`v → v+k mod 17`, `k = 1..8`)は 17頂点 oriented・`δ⁺ = 8`・強連結で、
§3 の点検に含まれている。よって最小値は 17 に達し、**N1**: `E_{δ≥8}(17) = 17`。

## 4. 審査を依頼する点

1. **Step 1**: oriented graph の弧数上限が `C(n,2)` であること、および等号成立から
   「トーナメント」と「正則」の両方が出ること
2. **Step 2**: 背理法の妥当性。とくに (a) `N⁺⁺` の「ちょうど距離2」定義との整合、
   (b) `u ≠ v` および `u ∉ N⁺(v)` の確認、(c) `N⁺(v) ⊆ N⁺(u)` から `|N⁺(u)| ≥ 9` を出す箇所
3. **Step 3**: 強連結制約の扱い。N2 は強連結を使わず、N1 は `A₁₇^sc ≠ ∅` のみを使う。
   この分離が正しいか
4. **U2 の判定**: 「非自明な上界がない」が誤りであるという結論が妥当か。
   誤りであるなら、内部の未決項目 U2 は閉じる
5. **向きの誤りの検査**: 主張が偽であるなら excess < 17 の `G ∈ A₁₇` が存在する。
   cap=4 INFEASIBLE(3083 s)はその不在と整合するが、`cap = 16` の INFEASIBLE は未実行である。
   **ソルバー結果との整合性を受理の根拠にしないこと**(反証の失敗は確定の材料にならない)。
   受理は Step 1〜3 の独立再導出のみに基づくこと

## 7. 追記(2026-07-25 深夜、監修受理後)— 一般形への差し替え

本報告書の Step 1〜3 は n = 17 に特化して書かれていたが、**同じ論法が
n = 2k+1・δ⁺ ≥ k の全ての k で通る**。内部側が確認し、コミット `b394d30` で
§11.1 A2 / §11.2 U2 / §11.8 A2 を更新済み。**公開文書ではこの一般形を正文とする。**

> **命題**: k ≥ 1 とする。n = 2k+1 頂点・最小出次数 ≥ k の向き付きグラフ G
> 全てについて excess(G) = n。よって **E_{δ≥k}(2k+1) = 2k+1**。
> 特に **E_{δ≥8}(17) = 17**。
>
> **証明**: n·k = C(n,2) なので G は正則トーナメント。v を任意の頂点、
> w ∈ N⁻(v) とする。w ∉ N⁺⁺(v) と仮定すると、全ての y ∈ N⁺(v) で w → y、
> よって N⁺(v) ⊆ N⁺(w)。w → v より v ∈ N⁺(w) かつ v ∉ N⁺(v) だから
> N⁺(v) ∪ {v} ⊆ N⁺(w)、すなわち |N⁺(w)| ≥ k+1 > k で矛盾。
> ゆえに N⁻(v) ⊆ N⁺⁺(v) で |N⁺⁺(v)| ≥ k。一方 |N⁺⁺(v)| ≤ n−1−k = k。
> よって d(v) = 0 が全頂点で成立し、excess = n。∎

本報告書 §1 の2段構成との関係:

- Step 1(トーナメント強制)は一般形の第1文と同一(`n·k = C(n,2)`)
- Step 2 の (⊇) 方向は一般形の背理法と同一。本報告書は `|N⁺(u)| ≥ 9` と
  17 固有の数値で書いたが、一般形は `|N⁺(w)| ≥ k+1 > k` と書く
- 一般形は (⊆) 方向を `|N⁺⁺(v)| ≤ n−1−k = k` として**上下から挟む**形にまとめており、
  本報告書のような集合等号 `N⁺⁺(v) = N⁻(v)` の明示を経由しない。より短い
- 監修の理論所見(`A₁₇^sc = A₁₇`)は一般形でもそのまま成立する
  (`N⁺⁺(v) = N⁻(v)` は挟み込みの等号成立から従うため)

**k = 4..8 で数値確認済み**(excess = 9, 11, 13, 15, 17)。公開側の検査は
`verify/check_t8.py` に置く。
